My Engineering Projects

These projects highlight my experience with machine learning, operating systems, digital circuit design, and control systems. Through these projects, I've developed programming, problem-solving, and engineering skills.

Machine Learning: Soccer Prediction Model

Project Overview

Developed a machine learning project to analyze soccer match data and estimate the probability that a possession results in a shot.

Technologies Used

  • Python
  • Bayesian Networks
  • Hidden Markov Models
  • Probabilistic Modeling
  • Data Preprocessing

My Contributions

Worked on Bayesian Network structure learning, including the PC algorithm and chi-squared independence testing. Helped develop the network model and contributed to the final project report.

What I Learned

This project helped me understand how probabilistic models can be used to analyze real-world data and how data preprocessing affects prediction accuracy.

Operating Systems: Nachos

Project Overview

Implemented operating system features in Nachos, an educational operating system used to understand how operating systems manage threads, processes, and memory.

Technologies Used

  • Java
  • Linux
  • Thread Synchronization
  • Virtual Memory
  • Process Management

My Contributions

Worked on thread synchronization, user program support, and virtual memory implementation. Tested operating system behavior using debugging tools and custom test cases.

What I Learned

This project improved my understanding of concurrency, memory management, and low-level system programming.

Digital Circuit Design: D Flip-Flop

Project Overview

Designed and simulated digital circuits using CMOS technology, including a D-type flip-flop. This project focused on transistor-level design and circuit behavior.

Technologies Used

  • Cadence Virtuoso
  • CMOS Logic
  • Transmission Gates
  • Digital Circuit Simulation

My Work

Worked with transistor-level circuit designs, clock signals, and circuit simulations to study digital logic behavior.

What I Learned

This project strengthened my understanding of digital circuit design and how transistor-level components are used to build sequential circuits.
